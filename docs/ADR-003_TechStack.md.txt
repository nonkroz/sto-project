# ADR-003: Технологічний стек на основі Python (FastAPI + React)

## Статус
Accepted

## Контекст
Ядром системи «CarPrice System» є алгоритми машинного навчання (ML-моделі на базі XGBoost/LightGBM або Scikit-learn), які розробляються та тренуються Аналітиком Даних. Для Frontend-частини потрібен гнучкий, швидкий та адаптивний SPA-інтерфейс, який дозволить користувачам зручно переглядати динамічні графіки трендів ринку та завантажувати PDF-звіти.

## Рішення
Використовувати мову **Python** та асинхронний фреймворк **FastAPI** для розробки Backend API, мову **JavaScript/TypeScript** та фреймворк **React.js** для створення Frontend-частини сайту.

## Обґрунтування
1. **Рідна інтеграція з Machine Learning:** Python є промисловим стандартом для Data Science. Використання FastAPI дозволяє запускати прогнозування та перенавчання моделей нативно, використовуючи ті самі структури даних (Pandas, NumPy), без потреби міжмовної взаємодії.
2. **Висока швидкість FastAPI:** Асинхронна природа фреймворку (ASGI) забезпечує продуктивність на рівні Node.js/Go, гарантуючи миттєву обробку запитів до API та автоматичну генерацію OpenAPI (Swagger) специфікації.
3. **Сучасний UI на React:** Забезпечує створення швидкого інтерактивного SPA-додатка з можливістю простої інтеграції бібліотек візуалізації графіків ринку (наприклад, Chart.js або Recharts).

## Альтернативи
- **Node.js (NestJS):** Відхилено. Не має зрілої та ефективної екосистеми для роботи з математичними матрицями та ML-моделями, що змусило б будувати складну архітектуру із викликом Python-скриптів.
- **Ruby on Rails:** Відхилено. Попри швидку генерацію базового CRUD, фреймворк є занадто важким та неефективним для інтеграції з сучасними інструментами штучного інтелекту й обробки великих аналітичних масивів даних у реальному часі.

## Наслідки
### Позитивні
- Максимальна швидкість інтеграції алгоритмів ШІ з серверною частиною додатка.
- Автоматична генерація та валідація контракту API (OpenAPI 3.0), що спрощує роботу фронтенд-розробника.
### Негативні
- Розробникам необхідно володіти двома різними екосистемами та мовами (Python для бекенду та JavaScript/TypeScript для фронтенду).
